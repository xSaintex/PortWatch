{# base/base_layout.html The shared HTML skeleton for every PortWatch page. All other templates extend this file using Jinja2's {% extends %} tag. HOW TO USE IN A CHILD TEMPLATE: {% extends "base/base_layout.html" %} {% block title %}My Page Title{% endblock %} {% block content %} ... your page HTML here ... {% endblock %} BLOCKS AVAILABLE: - title : Text shown in the browser tab - extra_head : Extra or tags for a specific page (optional) - content : The main page content - extra_scripts : Page-specific {# Chart.js — served locally #} {# PortWatch shared JavaScript (tooltips, mobile menu) #} {# PortWatch reusable pagination — available on every page #} {# Optional page-specific scripts from child templates #} {% block extra_scripts %}{% endblock %}
